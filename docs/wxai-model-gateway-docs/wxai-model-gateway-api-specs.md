Controls which (if any) function is called by the model.

logit_bias
Modifies the likelihood of specified tokens appearing in the completion. Accepts a JSON object that maps tokens (specified by their token ID in the tokenizer) to an associated bias value from -100 to 100. Mathematically, the bias is added to the logits generated by the model prior to sampling. The exact effect will vary per model, but values between -1 and 1 should decrease or increase likelihood of selection; values like -100 or 100 should result in a ban or exclusive selection of the relevant token.

An object specifying the format that the model must output.

Create Image Generations
Generates an image from a prompt using the provided model.

POST /ml/gateway/v1/images/generations


Authentication
This method uses the Bearer security scheme for authentication.

Request
Request Body
Required*

Image Generation Request

Example: dall-e-3

Required*
string
A text description of the desired image(s). For OpenAI, the maximum length is 32000 characters for gpt-image-1, and 1000 and 4000 characters respectively for dall-e-2 and dall-e-3.

Possible values: length ≥ 1

Example: Create an image of a dog

background
string
The background parameter allows to set transparency for the background for image generation.

In a request this parameter can be "auto" (default), "transparent" or "opaque". In the response this value not be "auto". When "auto" is used, the model will automatically determine the best background for the image. If "transparent", the "output_format" needs to support transparency, so it should be set to either "png" (default value) or "webp".

For OpenAI, this parameter is only supported for the gpt-image-1 model.

Allowable values: [auto,transparent,opaque]

Default: auto

Example: opaque

moderation
string
Control the content-moderation level for images. For OpenAI, this parameter is only supported by the gpt-image-1 model.

Must be either "low" for less restrictive filtering or "auto" (default value).

Allowable values: [low,auto]

Default: auto

Example: low

n
int32
The number of images to generate. Must be between 1 and 10. For OpenAI's dall-e-3, n only supports a value of 1.

Possible values: 1 ≤ value ≤ 10

Default: 1

Example: 5

output_compression
integer
The compression level (0-100%) for the generated images. This parameter is only supported for OpenAI's gpt-image-1 model with the "webp" or "jpeg" output formats, and defaults to 100.

Default: 100

Example: 50

output_format

Authentication
This method uses the Bearer security scheme for authentication.

Request
Request Body
Required*
ProvidersValidateRequest
Validation Request

Required*
string
The type of provider to validate (e.g., "openai", "anthropic", "watsonxai").

Example: openai

Data Reference is a reference to a remote credential store. For example, an IBM Cloud Secrets Manager secret. The value in the remote store is expected to be a JSON representation of the data field of a provider request.


DataReference
data
The credential details for validating the provider. This should be a JSON object matching the provider's configuration schema.


object

Response
Response Body
ProvidersValidateResponse
provider_type
Always included*
string
The provider type that was validated.

Example: openai

Always included*
boolean
Indicates whether the credential validation was successful. true = credentials are valid, false = validation failed

Example: true

message
string
A human-readable message describing the validation result. For successful validations (valid=true), this confirms the credentials are valid. For failed validations (valid=false), this provides details about why validation failed.

Example: Credentials validated successfully
